Client reference

A concise guide to using ml_app_client. Select a module below for its focused API documentation.

Import and sign in

from ml_app_client import MLAppClient

# Uses ML_APP_ACCESS_TOKEN when it is set.
# Otherwise it securely asks for login and password.
client = MLAppClient.connect()

# Confirm the authenticated account.
profile = client.me()
print(profile["login_name"])

For unattended scripts, set ML_APP_API_URL and ML_APP_ACCESS_TOKEN. The default API address is http://localhost:8000/api/v1.

Presenting results

Typed client objects contain useful fields, but their normal Python representation includes technical implementation details. Use display_object in a notebook to render a readable field table. It supports typed client models, mappings, and catalog pages; the internal raw payload is intentionally omitted.

# Render one result directly in an IPython / Jupyter notebook.
client.display_object(case, title="Business Case")

# Render each object from a bounded catalog page.
incoming = client.page_business_case_access_requests(box="mine")
for request in incoming.items:
    client.display_object(request, title="Access request")

# Return a rich view when calling your own display function.
display(client.present(incoming, title="Request page"))

Outside IPython, display_object prints the same fields as formatted text and still returns the presentation object.
